阿里云函数计算 FC 3.0 上传包

运行环境：Node.js 20
请求处理程序：index.handler
触发器：HTTP 触发器
允许方法：GET、OPTIONS
认证方式：无需认证（试用阶段）

接口示例：
  函数URL?q=周杰伦&year=2019&page=1

重要说明：
1. 免费试用阶段请先设置费用预警。
2. 只有国内函数节点实际测试通过后，才把函数URL写入 GitHub Pages。
3. 本程序只允许网页 https://qingnanzhi.github.io 发起浏览器跨域请求。
4. B站全站搜索使用的是网页端内部接口，不属于开放平台承诺稳定的公开 API。
