# B站时光机 2018—2020

一个搜索真实 B 站视频的时间胶囊网站。搜索范围固定在 2018 年 1 月 1 日至 2020 年 12 月 31 日，结果卡片可直接打开对应的 B 站 BV 页面。
## 功能

- 搜索真实的 B 站视频
- 严格限制 2018—2020 年发布时间
- 展示真实标题、封面、UP 主、播放量、弹幕数和发布时间
- 支持按 2018、2019、2020 单年筛选
- 支持综合排序、最多播放、最新发布三种 B 站原生排序
- 顶栏分区可按动画、音乐、知识、生活直接搜索
- 每页展示 24 个视频并支持翻页
- 点击卡片在新标签页打开对应 B 站视频
- 支持电脑和手机页面

## 说明

本项目为非官方概念站，与哔哩哔哩无隶属关系。视频信息来自 B 站公开页面接口，接口规则变化时可能需要维护。
